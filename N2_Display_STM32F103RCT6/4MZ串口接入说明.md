# 4MZ 氮气传感器串口接入

依据当前目录《4MZ气体传感器模组规格书v1.37新版.pdf》阅读结果整理。文件共 19 页，封面标注产品使用说明书 V1.3，声明页日期为 2024.09.01；下述页码为 PDF 页面序号。

## 硬件连接

第 4 页标注模组工作电压 3.6～5.5 V DC，UART 为 3.3 V 电平；第 6 页明确采用 5 V 供电、TTL 串口。该配置适用于手册所述的标准 UART 版本。

| 模组标识 | 含义 | 本工程连接 |
| --- | --- | --- |
| + | 电源正 | 5 V |
| - | 电源负 | GND，与 STM32 共地 |
| R | 模组 RX | PA9 / USART1_TX / UART1_TX |
| T | 模组 TX | PA10 / USART1_RX / UART1_RX |
| S | 电压输出 | 本方案不使用，悬空 |

第 6 页引脚图是底视图，画封装或接线时按实物方向核对。模组供电和 UART 电平分别是 5 V 和 3.3 V；标准版本可与 STM32 UART 直接连接。

当前 IOC：USART1=9600、8N1、无硬件流控，全双工并开启全局中断；USART2=115200、8N1，用作调试输出。采用内部 HSI/PLL 64 MHz，数码管、TIM3、SWD 的分配见《接线与配置说明.md》。

## 读取流程

第 7 页给出的通信方式为 Modbus RTU，默认从机地址 0x01，功能码 0x03。16 位寄存器数据高字节在前；CRC16 低字节在前。

上电首次读取寄存器 0x0000～0x0009，可同时获得单位、小数位、浓度、满量程、状态和气体类型。查询命令共 8 字节，按二进制发送：

```text
01 03 00 00 00 0A C5 CD
```

正常应答结构为 `01 03 14` + 20 字节寄存器数据 + 2 字节 CRC，共 25 字节。也要处理异常应答 `01 83 ... CRC`，以及长度不足、地址错误、CRC 错误和接收超时，不能只按固定 25 字节无条件解析。

仅查询当前浓度寄存器 0x0001 时，可发送手册第 8 页的命令：

```text
01 03 00 01 00 01 D5 CA
```

正常应答为 `01 03 02 浓度高字节 浓度低字节 CRC低 CRC高`，共 7 字节。仅读浓度前应已取得单位和小数位，且运行中仍应定期检查状态。

建议本项目先采用主机每 1 s 查询一次的方式；这是实现建议，手册第 16 页针对多地址轮询另有每次间隔 500 ms 以上的建议。9600、8N1 下，Modbus RTU 的 3.5 字符间隔约为 3.65 ms，发送下一帧前需保留帧间静默时间；传感器最大响应延迟未在手册中明确给出，接收超时应结合实机调整。

若实物处于主动上报模式，可依手册第 14 页使用厂家命令切为被动查询模式：

```text
FF 01 01 8B 00 52 00 00 00 00 21
```

该帧属于厂家调试协议，不是 Modbus RTU 请求帧。正常只读浓度使用上述 0x03 查询，无需发送标定或报警值设置命令。当前未与实物通信，也未修改传感器内部设置。

## 浓度、单位与状态

| 寄存器地址 | 含义 | 用途 |
| --- | --- | --- |
| 0x0000 | 单位与小数位编码 | 解释浓度、报警值和量程 |
| 0x0001 | 浓度原始整数值 | 换算为显示值 |
| 0x0004 | 满量程原始整数值 | 确认实际量程 |
| 0x0005 | 状态字，低 8 位有效 | 正常、预热、故障、报警、超量程等 |
| 0x0008 | 气体类型，高 8 位有效 | N2 为十进制 64，即 0x40 |

第 8～9 页的寄存器 0 定义为：单位编码在 bit15～12，小数位编码在 bit11～8。按第 9 页表格读取为数值编码时：

| 字段 | 编码 | 含义 |
| --- | --- | --- |
| 单位 | 0x0 / 0x2 / 0x4 / 0x6 / 0x8 / 0xA | ppm / %LEL / %VOL / mg/m³ / ppb / ℃ |
| 小数位 | 0x0 / 0x4 / 0x8 / 0xC | 0 / 1 / 2 / 3 位小数 |

浓度 = 寄存器 1 原始整数值 ÷ 10^小数位数。注意小数位字段不能直接当作十进制小数位数，应使用表格映射。该编码方式较特殊，首次连接应打印原始寄存器值并核对实物，不要静默接受未知编码。

例如，若实际读取寄存器 0 为 0x4400，则按该表表示 %VOL、一位小数；寄存器 1 若为 781，则显示浓度为 78.1 %VOL。此例为协议换算示例，并非实测数据或对氮气出厂设置的断言。

气体类型应检查 `(寄存器8 >> 8) == 0x40`。不能将整个寄存器 8 直接与十进制 64 比较。

手册第 9 页将状态 0x00 定义为预热，0x01 为正常，0x02 为数据错误，0x03 为传感器故障，0x05/0x06 为低报/高报，0x08 为超量程。程序应区分有效测量及其报警状态、故障和通信超时。通信失败时可以显示 `---` 或约定错误码，避免把失效数据显示为正常浓度 0。

## 三位数码管与选型边界

三位数码管可显示 78.1、99.9；100.0 需要四位数字。若实际量程上限为 100 %VOL，建议在达到 100 时显示 `100`，其他范围可按需要保留一位小数。若希望全量程统一显示一位小数，需要四位数码管。

本手册是通用模组说明：气体类型表列出 N2=64，但第 4～5 页订购参数表未列出氮气版本的专用量程、分辨率、精度及测量原理。因此应以购买的完整型号、实物标签和厂商对应氮气版本资料确认这些参数，不能把其他气体型号的指标套用到氮气版本。

第 3 页提到上位机可加预热，推荐 180 s，而参数表又写预热时间 0 s。实现时至少读取预热状态，并结合氮气具体版本确定启动稳定等待时间。

当前 STM32F103RCT6 工程已加入 USART1 查询、N2 数据解析、数码管扫描和 USART2 诊断输出。显示采用 100 显示 `100`、其他有效值保留一位小数的规则，完整使用方法见《程序使用说明.md》。未编译代码，也未进行实物通信测试。
